*** SOLAR SYSTEM

A simple and interactive **Solar System** project created using **HTML and CSS**.

** Features

*  Displays the Sun and planets
*  Shows the planets in the Solar System
*  Includes a space/star background
*  Designed using HTML and CSS
*  Simple and easy-to-understand project

** Technologies Used

* HTML5
* CSS3

** Project Structure

```text
solar-system/
│
├── index.html
├── style.css
├── sun.png
├── solar1.webp
├── solar2.png
├── solar3.webp
├── solar4.webp
├── solar5.png
├── solar6.png
├── solar7.png
├── solar8.png
└── stars.webp
```

** How to Run

1. Clone this repository:

```bash
git clone https://github.com/visweswararaopappala/solar-system.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.

That's it!

** Purpose

This project was created to practice **HTML and CSS** and to build a simple visual representation of our Solar System.
